# New project

Started from the project template, so it already has the safety setup: changes go through branches and pull requests, and secrets, recordings and customer details can't be committed.

Open Claude in this folder and say what you want to build. Claude writes this README with you.

## Recipes

`recipes/` holds step-by-step setups Claude can follow: `recipes/computer-setup.md` (a new Windows PC, from just Claude Code to working projects) and `recipes/idea-hq.md` ("set up my Idea HQ"). New projects delete this folder in their first pull request.
